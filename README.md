# Trove — Student-Powered Campus Circulation Network

> **Circulate Knowledge. Share Essentials. Empower Your Campus.**

Trove is a student-powered web platform that enables the circulation of academic resources and everyday campus essentials within trusted university communities. By facilitating the buying, selling, renting, exchanging, and sharing of valuable resources, Trove helps students reduce costs, minimize waste, and maximize the value of underutilized assets—fostering an accessible, sustainable, and connected campus economy.

---

## 🌟 Key Features

### 1. 🎓 Campus Trust Circles (Vellore Institute of Technology - @vit.edu)
- Locked to verified university domains (`@vit.edu`) with campus switching for VIT Vellore, VIT Chennai, VIT-AP, and VIT Bhopal.
- Instant campus switcher that dynamically adapts local listings, safe meetup spots (SJT Gazebo, TT Foodys, Central Library), and university impact goals.
- All monetary metrics, prices, and deposit calculations in Indian Rupees (`₹`).

### 2. 🔄 5 Dynamic Circulation Modes
- 🏷️ **Buy / Sell**: Peer-to-peer student pricing (60-80% cheaper than the campus store).
- 📅 **Borrow / Rent**: Rent by day, week, or full semester (ideal for Casio fx-991CW calculators, engineering mini-drafters, bicycles, dorm essentials).
- 🔄 **Exchange / Swap**: Direct barter (e.g. trading engineering graphics drafter for calculus textbooks).
- 🎁 **Free Share / Pay-It-Forward**: Zero-cost community sharing to keep dorm items out of dumpsters during semester-end moves.
- 🚨 **Wishlist / Wanted Board**: Broadcast requests to peers who have idle gear in their dorm rooms.

### 3. 🌱 Campus Circular Economy & Sustainability Hub
- **Interactive Semester Savings Calculator**: Students slide their expected textbook, tech, and dorm needs to calculate instant rupee savings (`₹`) and CO₂ offset.
- Real-time campus impact metrics: student rupees saved, kg of CO₂ prevented, and landfill waste diverted.
- Verified badges: *Eco Sentinel*, *Top Lender*, *Study Hero*, *Safe Zone Certified*.

### 4. 🌙 Full Dark Mode Support & Custom Branding
- Seamless Light / Dark mode toggle in the navigation header with `localStorage` memory and system-preference detection.
- Custom tri-petal logo branding.

### 5. 🛡️ Safe Campus Meetup Zones
- Officially designated, high-visibility campus spots (*SJT Ground Floor Gazebo*, *TT Foodys Plaza*, *Periyar EVR Central Library Lobby*, *Anna Auditorium Promenade*).
- Built-in safe exchange code generation (`#TRV-XXXX`).
- Four Golden Safety Tenets guide & VIT Campus Security Emergency Dispatch (`0416-220-2101`).

### 5. 💬 Campus Chat & Negotiation Simulator
- In-app student chat simulator for scheduling safe meetups, agreeing on pricing/Venmo, and locking in handoff spots.

### 6. ✨ Fast Interactive Modals & Confetti Feedback
- Resource detail modal with direct purchase, rental duration calculator, and barter forms.
- Interactive "+ Circulate an Asset" listing wizard with real-time eco-impact estimate.
- Wishlist request broadcaster.

## 🚀 Quickstart

```bash
# Clone or open the project folder
cd trove

# Install dependencies (if not already installed)
npm install

# Start the Vite local development server
npm run dev

# Open in browser:
http://127.0.0.1:5173/
```

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
- **Typography**: Plus Jakarta Sans & Inter
